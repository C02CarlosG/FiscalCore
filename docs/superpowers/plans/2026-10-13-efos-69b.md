# EFOS (lista 69-B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que FiscalCore importe la lista 69-B del SAT (automática semanal, forzada o manual), cruce los CFDI recibidos por RFC del emisor y lo muestre en una pantalla EFOS, en el listado de CFDI y en Proveedores.

**Architecture:** Parser puro (`efos.py`) → importación atómica con salvaguardas (`efos_datos.py`) → tabla `efos_lista` + vista `efos_vigente`. El cruce se hace con un filtro `efos` y una columna `situacion_69b` en el listado de CFDI existente (`cfdi_listado`/`cfdi_columnas`), de modo que lista, conteos, totales y exportación coinciden por construcción. La pantalla EFOS reutiliza `CfdiPantalla`. El worker descarga una vez por semana.

**Tech Stack:** Python 3.11 / FastAPI / psycopg2 / pytest; Next.js + TypeScript + TanStack Query + vitest.

**Spec:** `docs/superpowers/specs/2026-10-13-efos-69b-design.md`

## Global Constraints

- Migración SQL idempotente, numerada **073** (la 072 es del criterio de efectivo), registrada en `backend/db.py::init_db`.
- Todo endpoint nuevo en `docs/openapi.yaml` (`backend/tests/test_openapi_sync.py`); los parámetros nuevos de `/cfdis` también.
- Todo valor leído del CSV o del usuario viaja como parámetro SQL; nunca se interpola.
- Archivo del SAT = dato no confiable: máximo 50 MB, cabecera exacta de 20 columnas, `cp1252`, se rechaza si más de 1 % de las filas son inválidas o si las filas caen más de 20 % frente a la última importación correcta.
- La importación reemplaza `efos_lista` en **una sola transacción**: si falla, la lista anterior queda intacta.
- Descarga: solo `http://` o `https://`, tiempo máximo 60 s, URL por `EFOS_URL` (por defecto la del SAT).
- Solo administradores de plataforma (`deps.require_admin`) pueden importar/subir; todo queda en `auditoria`.

## Review Focus

1. **RFC repetido con situación distinta** (p. ej. `AAS110331G59`: Definitivo en la fila 155, Sentencia Favorable en la 156): la situación vigente es la de mayor `No` y el historial conserva ambas. Pruebas en Tareas 1 y 3.
2. **El SAT responde 200 con una página HTML de error o un CSV truncado**: la cabecera o la caída de filas lo rechazan y la lista anterior queda intacta. Pruebas en Tareas 1 y 3.
3. **CFDI cancelado de un proveedor en la lista** no aparece; **un CFDI emitido** por la empresa nunca aparece, ni con el filtro `efos`. Prueba en Tarea 5.
4. **RFC del emisor con minúsculas o espacios** en `cfdi.rfc_emisor` aún cruza. Prueba en Tarea 5.
5. **Todavía no hay lista importada**: la API de estado dice `desactualizada` y la pantalla muestra un estado vacío claro, no un error. Pruebas en Tareas 3 y 7.
6. **Falla de red o del SAT en el worker**: se registra como `fallida`, se reintenta en una hora y no detiene la descarga de CFDI. Prueba en Tarea 4.

    salida = io.StringIO()
    w = csv.writer(salida, lineterminator="\r\n")
    if preambulo:
        w.writerow([f"Información actualizada al {actualizada}; los listados a que se hace mención son públicos."])
        w.writerow(["Listado completo de contribuyentes (Artículo 69-B del CFF)"] + [""] * 19)
    w.writerow(list(encabezado if encabezado is not None else efos.COLUMNAS))
    for f in filas:
        w.writerow(f)
    return salida.getvalue().encode("cp1252")

    """``n`` filas válidas con RFC distintos (ABC + 6 dígitos + 3 caracteres)."""
    return [fila(desde + i, f"ABC{(desde + i):06d}AB1", f"CONTRIBUYENTE {desde + i}", "Definitivo", definitivo="01/08/2018")
            for i in range(n)]

```python
"""Lista 69-B del SAT (spec 2026-10-13-efos-69b-design): lectura y validación del CSV.

Sin base de datos ni red. El archivo es un dato **no confiable** (se descarga por HTTP sin TLS): se valida
la cabecera, cada fila y la proporción de filas inválidas, y nada se interpola en SQL.
"""
from __future__ import annotations

import csv
import io
import re
import unicodedata
from dataclasses import dataclass
from datetime import date, datetime
from typing import Optional

MAX_BYTES = 50 * 1024 * 1024
MAX_DESCARTE = 0.01          # más de 1 % de filas inválidas: el archivo no es confiable
CAIDA_MAXIMA = 0.20          # menos filas que 80 % de la importación anterior: archivo truncado o manipulado
RFC_GENERICO = "XXXXXXXXXXXX"
_RFC_RE = re.compile(r"[A-ZÑ&]{3,4}\d{6}[A-Z0-9]{3}")

SITUACIONES = ("Presunto", "Desvirtuado", "Definitivo", "Sentencia Favorable")
RIESGO = {"Presunto": "alto", "Definitivo": "critico", "Desvirtuado": "informativo", "Sentencia Favorable": "informativo"}
_POR_MINUSCULAS = {s.casefold(): s for s in SITUACIONES}

COLUMNAS = (
    "No", "RFC", "Nombre del Contribuyente", "Situación del contribuyente",
    "Número y fecha de oficio global de presunción SAT", "Publicación página SAT presuntos",
    "Número y fecha de oficio global de presunción DOF", "Publicación DOF presuntos",
    "Número y fecha de oficio global de contribuyentes que desvirtuaron SAT", "Publicación página SAT desvirtuados",
    "Número y fecha de oficio global de contribuyentes que desvirtuaron DOF", "Publicación DOF desvirtuados",
    "Número y fecha de oficio global de definitivos SAT", "Publicación página SAT definitivos",
    "Número y fecha de oficio global de definitivos DOF", "Publicación DOF definitivos",
    "Número y fecha de oficio global de sentencia favorable SAT", "Publicación página SAT sentencia favorable",
    "Número y fecha de oficio global de sentencia favorable DOF", "Publicación DOF sentencia favorable",
)

# (etapa, origen) → (columna del oficio, columna de la fecha)
_ETAPAS = {
    "presunto_sat": (4, 5), "presunto_dof": (6, 7),
    "desvirtuado_sat": (8, 9), "desvirtuado_dof": (10, 11),
    "definitivo_sat": (12, 13), "definitivo_dof": (14, 15),
    "sentencia_sat": (16, 17), "sentencia_dof": (18, 19),
}
_ETAPA_DE_SITUACION = {"Presunto": "presunto_sat", "Desvirtuado": "desvirtuado_sat",
                       "Definitivo": "definitivo_sat", "Sentencia Favorable": "sentencia_sat"}

_MESES = {"enero": 1, "febrero": 2, "marzo": 3, "abril": 4, "mayo": 5, "junio": 6, "julio": 7, "agosto": 8,
          "septiembre": 9, "setiembre": 9, "octubre": 10, "noviembre": 11, "diciembre": 12}
_ACTUALIZADA = re.compile(r"actualizada\s+al\s+(\d{1,2})\s+de\s+([a-záéíóú]+)\s+de\s+(\d{4})", re.IGNORECASE)


class ErrorImportacion(ValueError):
    """El archivo no se puede importar; el mensaje es apto para mostrarse al administrador."""


@dataclass(frozen=True)
class FilaEfos:
    no_sat: int
    rfc: str
    nombre: str
    situacion: str
    fechas: dict
    oficios: dict


@dataclass(frozen=True)
class ResultadoParseo:
    fecha_archivo: Optional[date]
    filas: list
    leidas: int
    descartadas: int
    genericas: int


def _norm(texto: str) -> str:
    return unicodedata.normalize("NFC", texto).strip()


def _fecha_del_preambulo(filas: list) -> Optional[date]:
    for fila in filas[:5]:
        for celda in fila:
            m = _ACTUALIZADA.search(celda)
            if m and m.group(2).casefold() in _MESES:
                try:
                    return date(int(m.group(3)), _MESES[m.group(2).casefold()], int(m.group(1)))
                except ValueError:
                    return None
    return None


def _indice_cabecera(filas: list) -> int:
    for i, fila in enumerate(filas):
        if len(fila) >= 2 and _norm(fila[0]) == "No" and _norm(fila[1]) == "RFC":
            return i
    raise ErrorImportacion("No se encontró la cabecera esperada (No, RFC, …) en el archivo")


def _fecha(valor: str) -> Optional[date]:
    valor = valor.strip()
    return datetime.strptime(valor, "%d/%m/%Y").date() if valor else None


def _fila(fila: list) -> Optional[FilaEfos]:
    """La fila validada, o ``None`` si es inválida."""
    if len(fila) < len(COLUMNAS):
        return None
    try:
        no = int(fila[0].strip())
        situacion = _POR_MINUSCULAS.get(_norm(fila[3]).casefold())
        rfc = fila[1].strip().upper()
        if situacion is None or not _RFC_RE.fullmatch(rfc):
            return None
        fechas = {k: _fecha(fila[f]) for k, (_, f) in _ETAPAS.items()}
    except ValueError:
        return None
    oficios = {k: _norm(fila[o]) for k, (o, _) in _ETAPAS.items()}
    return FilaEfos(no, rfc, _norm(fila[2]), situacion, fechas, oficios)


def parsear(contenido: bytes) -> ResultadoParseo:
    if len(contenido) > MAX_BYTES:
        raise ErrorImportacion(f"El archivo excede el tamaño máximo de {MAX_BYTES // (1024 * 1024)} MB")
    try:
        texto = contenido.decode("cp1252")
    except UnicodeDecodeError:
        raise ErrorImportacion("El archivo no está en codificación cp1252")
    filas = list(csv.reader(io.StringIO(texto)))
    fecha_archivo = _fecha_del_preambulo(filas)
    i = _indice_cabecera(filas)
    if [_norm(c) for c in filas[i]] != [_norm(c) for c in COLUMNAS]:
        raise ErrorImportacion("La cabecera del archivo no es la esperada (20 columnas del listado 69-B)")

    validas, descartadas, genericas = [], 0, 0
    for crudo in filas[i + 1:]:
        if not any(c.strip() for c in crudo):
            continue
        if len(crudo) > 1 and crudo[1].strip().upper() == RFC_GENERICO:
            genericas += 1
            continue
        fila = _fila(crudo)
        if fila is None:
            descartadas += 1
        else:
            validas.append(fila)

    leidas = len(validas) + descartadas + genericas
    if not validas:
        raise ErrorImportacion("El archivo no trae filas válidas (sin filas de contribuyentes)")
    if descartadas / leidas > MAX_DESCARTE:
        raise ErrorImportacion(f"{descartadas} de {leidas} filas son inválidas (más de {int(MAX_DESCARTE * 100)} %)")
    return ResultadoParseo(fecha_archivo, validas, leidas, descartadas, genericas)


def validar_contra_anterior(nuevas: int, anteriores: Optional[int]) -> None:
    """Rechaza un archivo con muchas menos filas que la última importación correcta (truncado o manipulado)."""
    if anteriores and nuevas < anteriores * (1 - CAIDA_MAXIMA):
        raise ErrorImportacion(
            f"Caída sospechosa de filas: {nuevas} contra {anteriores} de la importación anterior (más de 20 %)")


def fecha_de_etapa(situacion: str, fechas: dict) -> Optional[date]:
    """Fecha de publicación en la página del SAT de la etapa que corresponde a la situación vigente."""
    return fechas.get(_ETAPA_DE_SITUACION.get(situacion, ""))
```

-- 073: lista 69-B del SAT (spec 2026-10-13-efos-69b-design). Idempotente.
-- efos_importaciones: bitácora de cada intento (también los fallidos y los "sin cambios").
-- efos_lista: filas de la última importación correcta (se reemplaza completa en una transacción).
-- efos_vigente: por RFC, la fila con mayor No (el SAT enumera cronológicamente: la última es la situación vigente).

CREATE TABLE IF NOT EXISTS efos_importaciones (
    id            BIGSERIAL PRIMARY KEY,
    origen        TEXT NOT NULL CHECK (origen IN ('automatica', 'manual')),
    usuario_id    UUID REFERENCES usuarios(id) ON DELETE SET NULL,
    fecha_archivo DATE,
    sha256        TEXT,
    filas         INT NOT NULL DEFAULT 0,
    rfc_unicos    INT NOT NULL DEFAULT 0,
    estado        TEXT NOT NULL CHECK (estado IN ('correcta', 'fallida', 'sin_cambios')),
    mensaje       TEXT,
    creado_en     TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_efos_importaciones_reciente ON efos_importaciones (estado, creado_en DESC);

CREATE TABLE IF NOT EXISTS efos_lista (
    importacion_id        BIGINT NOT NULL REFERENCES efos_importaciones(id),
    no_sat                INT NOT NULL,
    rfc                   VARCHAR(13) NOT NULL,
    nombre                TEXT NOT NULL DEFAULT '',
    situacion             TEXT NOT NULL CHECK (situacion IN ('Presunto', 'Desvirtuado', 'Definitivo', 'Sentencia Favorable')),
    fecha_presunto_sat    DATE,
    fecha_presunto_dof    DATE,
    fecha_desvirtuado_sat DATE,
    fecha_desvirtuado_dof DATE,
    fecha_definitivo_sat  DATE,
    fecha_definitivo_dof  DATE,
    fecha_sentencia_sat   DATE,
    fecha_sentencia_dof   DATE,
    oficios               JSONB NOT NULL DEFAULT '{}'::jsonb,
    PRIMARY KEY (importacion_id, no_sat)
);

CREATE INDEX IF NOT EXISTS idx_efos_lista_rfc ON efos_lista (rfc);

CREATE OR REPLACE VIEW efos_vigente AS
SELECT DISTINCT ON (l.rfc) l.*
FROM efos_lista l
ORDER BY l.rfc, l.no_sat DESC;
```

"""Lista 69-B del SAT: importación atómica, estado y consulta por RFC (spec 2026-10-13-efos-69b-design)."""
from __future__ import annotations

import hashlib
from datetime import date
from typing import Iterable, Optional

import psycopg2.extras

from . import db, efos

DIAS_DESACTUALIZADA = 45

_COLUMNAS_FECHA = ("presunto_sat", "presunto_dof", "desvirtuado_sat", "desvirtuado_dof",
                   "definitivo_sat", "definitivo_dof", "sentencia_sat", "sentencia_dof")


def _registrar(origen: str, usuario_id: Optional[str], estado: str, mensaje: Optional[str], sha: Optional[str] = None,
               fecha_archivo: Optional[date] = None, filas: int = 0, rfc_unicos: int = 0) -> None:
    db.execute(
        """INSERT INTO efos_importaciones (origen, usuario_id, fecha_archivo, sha256, filas, rfc_unicos, estado, mensaje)
           VALUES (%s, %s, %s, %s, %s, %s, %s, %s)""",
        (origen, usuario_id, fecha_archivo, sha, filas, rfc_unicos, estado, mensaje))


def importar(contenido: bytes, origen: str, usuario_id: Optional[str] = None) -> dict:
    """Importa el CSV. Todo o nada: ante cualquier falla la lista anterior queda intacta y el intento queda
    registrado como ``fallida``. Un archivo idéntico al de la última importación correcta no cambia nada."""
    sha = hashlib.sha256(contenido).hexdigest()
    try:
        ultima = db.query_one(
            "SELECT sha256, filas, rfc_unicos, fecha_archivo FROM efos_importaciones "
            "WHERE estado = 'correcta' ORDER BY creado_en DESC, id DESC LIMIT 1")
        if ultima and ultima["sha256"] == sha:
            _registrar(origen, usuario_id, "sin_cambios", "Archivo idéntico al de la última importación", sha,
                       ultima["fecha_archivo"], ultima["filas"], ultima["rfc_unicos"])
            return {"estado": "sin_cambios", "filas": ultima["filas"], "rfc_unicos": ultima["rfc_unicos"],
                    "fecha_archivo": ultima["fecha_archivo"].isoformat() if ultima["fecha_archivo"] else None,
                    "descartadas": 0, "genericas": 0}
        resultado = efos.parsear(contenido)
        efos.validar_contra_anterior(len(resultado.filas), ultima["filas"] if ultima else None)
    except efos.ErrorImportacion as exc:
        _registrar(origen, usuario_id, "fallida", str(exc), sha)
        raise
    rfc_unicos = len({f.rfc for f in resultado.filas})
    try:
        with db.get_conn() as conn:
            with conn.cursor() as cur:
                cur.execute(
                    """INSERT INTO efos_importaciones (origen, usuario_id, fecha_archivo, sha256, filas, rfc_unicos, estado)
                       VALUES (%s, %s, %s, %s, %s, %s, 'correcta') RETURNING id""",
                    (origen, usuario_id, resultado.fecha_archivo, sha, len(resultado.filas), rfc_unicos))
                importacion_id = cur.fetchone()[0]
                cur.execute("DELETE FROM efos_lista")
                valores = [
                    (importacion_id, f.no_sat, f.rfc, f.nombre, f.situacion, *(f.fechas[k] for k in _COLUMNAS_FECHA),
                     psycopg2.extras.Json(f.oficios))
                    for f in resultado.filas
                ]
                psycopg2.extras.execute_values(
                    cur,
                    "INSERT INTO efos_lista (importacion_id, no_sat, rfc, nombre, situacion, "
                    + ", ".join(f"fecha_{k}" for k in _COLUMNAS_FECHA) + ", oficios) VALUES %s",
                    valores, page_size=2000)
    except Exception as exc:
        _registrar(origen, usuario_id, "fallida", f"Error al guardar la lista: {exc}", sha)
        raise
    return {"estado": "correcta", "filas": len(resultado.filas), "rfc_unicos": rfc_unicos,
            "fecha_archivo": resultado.fecha_archivo.isoformat() if resultado.fecha_archivo else None,
            "descartadas": resultado.descartadas, "genericas": resultado.genericas}


def estado(hoy: Optional[date] = None) -> dict:
    """Estado de la lista vigente y del último intento de importación."""
    hoy = hoy or date.today()
    ultimo = db.query_one(
        "SELECT estado, mensaje, creado_en FROM efos_importaciones ORDER BY creado_en DESC, id DESC LIMIT 1")
    intento = {"estado": ultimo["estado"], "mensaje": ultimo["mensaje"], "creado_en": ultimo["creado_en"].isoformat()} if ultimo else None
    fila = db.query_one(
        "SELECT fecha_archivo, creado_en, filas, rfc_unicos FROM efos_importaciones "
        "WHERE estado = 'correcta' ORDER BY creado_en DESC, id DESC LIMIT 1")
    if not fila:
        return {"hay_lista": False, "fecha_archivo": None, "importada_en": None, "filas": 0, "rfc_unicos": 0,
                "dias_de_antiguedad": None, "desactualizada": True, "ultimo_intento": intento}
    referencia = fila["fecha_archivo"] or fila["creado_en"].date()
    dias = (hoy - referencia).days
    return {"hay_lista": True,
            "fecha_archivo": fila["fecha_archivo"].isoformat() if fila["fecha_archivo"] else None,
            "importada_en": fila["creado_en"].isoformat(), "filas": fila["filas"], "rfc_unicos": fila["rfc_unicos"],
            "dias_de_antiguedad": dias, "desactualizada": dias > DIAS_DESACTUALIZADA, "ultimo_intento": intento}


def situaciones_de(rfcs: Iterable[str]) -> dict:
    """Situación vigente, riesgo y fecha de publicación de la etapa, para los RFC que están en la lista."""
    lista = sorted({r.strip().upper() for r in rfcs if r})
    if not lista:
        return {}
    filas = db.query_all(
        "SELECT rfc, situacion, " + ", ".join(f"fecha_{k}" for k in _COLUMNAS_FECHA)
        + " FROM efos_vigente WHERE rfc = ANY(%s)", (lista,))
    resultado = {}
    for f in filas:
        fechas = {k: f[f"fecha_{k}"] for k in _COLUMNAS_FECHA}
        fecha = efos.fecha_de_etapa(f["situacion"], fechas)
        resultado[f["rfc"]] = {"situacion": f["situacion"], "riesgo": efos.RIESGO[f["situacion"]],
                               "fecha_publicacion": fecha.isoformat() if fecha else None}
    return resultado
```

def descargar(url: Optional[str] = None, timeout: int = 60) -> bytes:
    """Descarga el CSV. La URL viene de configuración (``EFOS_URL``), nunca del usuario; solo http/https."""
    url = url or os.environ.get("EFOS_URL") or URL_POR_DEFECTO
    if not url.lower().startswith(("http://", "https://")):
        raise ValueError("La URL de la lista 69-B debe ser http o https")
    peticion = urllib.request.Request(url, headers={"User-Agent": "FiscalCore/1.0"})
    with urllib.request.urlopen(peticion, timeout=timeout) as respuesta:
        datos = respuesta.read(efos.MAX_BYTES + 1)
    if len(datos) > efos.MAX_BYTES:
        raise efos.ErrorImportacion("El archivo del SAT excede el tamaño máximo")
    return datos


def toca_descargar(ahora: Optional[datetime] = None) -> bool:
    """Cada 7 días desde la última importación automática; tras una falla, se reintenta en una hora."""
    ahora = ahora or datetime.now(timezone.utc)
    ultimo = db.query_one(
        "SELECT estado, creado_en FROM efos_importaciones WHERE origen = 'automatica' ORDER BY creado_en DESC, id DESC LIMIT 1")
    if ultimo is None:
        return True
    espera = REINTENTO_TRAS_FALLA if ultimo["estado"] == "fallida" else timedelta(days=DIAS_ENTRE_DESCARGAS)
    return ahora - ultimo["creado_en"] >= espera


def ciclo_efos(ahora: Optional[datetime] = None) -> Optional[str]:
    """Una vuelta del worker: descarga e importa si toca. Nunca lanza; devuelve el estado o ``None`` si no tocaba."""

        _registrar("automatica", None, "fallida", f"No se pudo descargar: {exc}")
    return "fallida"

        resultado = efos_datos.importar(contenido, "manual", usuario_id)

"use client";

import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { apiFetch } from "@/lib/api-client";
import type { EfosEstado } from "@/types/api";

/** Estado de la lista 69-B: fecha del archivo del SAT, antigüedad y último intento de importación. */
export function useEfosEstado() {
  return useQuery({ queryKey: ["efos-estado"], queryFn: () => apiFetch<EfosEstado>("/api/v1/efos/estado") });
}

function useRefrescar() {
  const cliente = useQueryClient();
  return () => {
    cliente.invalidateQueries({ queryKey: ["efos-estado"] });
    for (const k of ["cfdi-listado", "cfdi-resumen", "proveedores"]) cliente.invalidateQueries({ queryKey: [k] });
  };
}

/** Descarga la lista del SAT ahora (solo administradores de la plataforma). */
export function useImportarEfos() {
  const refrescar = useRefrescar();
  return useMutation({
    mutationFn: () => apiFetch<unknown>("/api/v1/admin/efos/importar", { method: "POST" }),
    onSuccess: refrescar,
  });
}

/** Sube un CSV de la lista a mano (solo administradores de la plataforma). */
export function useSubirEfos() {
  const refrescar = useRefrescar();
  return useMutation({
    mutationFn: (archivo: File) => {
      const datos = new FormData();
      datos.append("archivo", archivo);
      return apiFetch<unknown>("/api/v1/admin/efos/subir", { method: "POST", body: datos });
    },
    onSuccess: refrescar,
  });
}

"use client";

import { useRef, useState } from "react";
import { Button } from "@/components/ui/button";
import { useEfosEstado, useImportarEfos, useSubirEfos } from "@/hooks/useEfos";
import { loadSession } from "@/lib/auth";

const fecha = (iso: string | null) => (iso ? iso.slice(0, 10).split("-").reverse().join("/") : "—");

/** Franja con el estado de la lista 69-B del SAT; los administradores de la plataforma pueden actualizarla. */
export function EfosFranja() {
  const estado = useEfosEstado();
  const importar = useImportarEfos();
  const subir = useSubirEfos();
  const entrada = useRef<HTMLInputElement>(null);
  const [error, setError] = useState<string | null>(null);
  const esAdmin = typeof window !== "undefined" && loadSession()?.rol === "admin";
  const d = estado.data;

  async function ejecutar(accion: () => Promise<unknown>) {
    setError(null);
    try {
      await accion();
    } catch (e) {
      setError(e instanceof Error ? e.message : "No se pudo actualizar la lista.");
    }
  }

  return (
    <section aria-label="Estado de la lista 69-B" className="space-y-2 rounded-md border bg-card p-3 text-sm">
      {d?.hay_lista ? (
        <p>
          Lista del SAT actualizada al <strong>{fecha(d.fecha_archivo)}</strong> · importada el {fecha(d.importada_en)} ·{" "}
          {d.rfc_unicos.toLocaleString("es-MX")} RFC
        </p>
      ) : (
        d && <p role="alert">Todavía no hay una lista 69-B importada. Un administrador de la plataforma debe importarla.</p>
      )}
      {d?.hay_lista && d.desactualizada && (
        <p role="alert" className="text-status-pendiente">
          La lista está desactualizada ({d.dias_de_antiguedad} días): el SAT puede haber publicado contribuyentes nuevos.
        </p>
      )}
      {d?.ultimo_intento?.estado === "fallida" && (
        <p className="text-xs text-muted-foreground">Último intento fallido: {d.ultimo_intento.mensaje}</p>
      )}
      {esAdmin && (
        <div className="flex flex-wrap items-center gap-2">
          <Button type="button" size="sm" variant="outline" disabled={importar.isPending} onClick={() => ejecutar(() => importar.mutateAsync())}>
            {importar.isPending ? "Actualizando…" : "Actualizar ahora"}
          </Button>
          <label className="text-xs">
            <span className="sr-only">Subir CSV</span>
            <input
              ref={entrada}
              type="file"
              accept=".csv"
              aria-label="Subir CSV"
              disabled={subir.isPending}
              onChange={(e) => {
                const archivo = e.target.files?.[0];
                if (archivo) ejecutar(() => subir.mutateAsync(archivo));
                if (entrada.current) entrada.current.value = "";
              }}
            />
          </label>
        </div>
      )}
      {error && (
        <p role="alert" className="text-xs text-destructive">
          {error}
        </p>
      )}
    </section>
